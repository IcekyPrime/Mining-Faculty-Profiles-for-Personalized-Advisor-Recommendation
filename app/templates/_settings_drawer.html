关于项目

AI3602 数据挖掘课程项目：采集公开信息 → 处理层建模 → Web 应用呈现。

数据从哪来
  • 五个学院官网的公开教师主页：职称、研究所、邮箱、研究方向、荣誉、主页链接
  • 选课社区的课程评价：课程名、课程号、评分与评分人数、开课学期
  • Semantic Scholar / AMiner 等学术数据库：h 指数、引用量、论文数、代表论文

只采公开信息，控制请求频率；数据仅用于课程学习。

两个评分并存
  • 原始 v1：论文 0.10 / 引用 0.20 / 荣誉 0.35 / 教学 0.25，5%–95% 截断；论文或引用缺失按 0 计，教学缺失用全库均值填充
  • 改进 v2：未知不参与计算、权重按可用维度归一、分位数排名、向中位数收缩
  • 档案页会同时给出两个分数与五维分项，方便对照算法差异
处理层用了什么
文本jieba 分词 + TF-IDF，领域词表与停用词统一口径
相似Shingling + MinHash + LSH，Jaccard ≥ 0.25
链接分析PageRank / HITS（合作网络）
社区发现关键词 kNN 相似图 + Louvain，模块度 ≈ 0.683，23 个研究相似社区
聚类SVD + K-means，轮廓系数自动选 K（当前 K=8，仅使用研究方向）
关联规则Apriori，min_support 0.02 / min_conf 0.3
已知限制
  • 合作网络覆盖 729 人：其余教师论文只有作者缩写或无法实体对齐，合作边不代表完整合作关系
  • 引用量 722 人、论文数 752 人有值，其余为未知（NULL），不参与 v2 评分
  • 教学评分只统计有公开点评的课程，覆盖 498 人
  • 排序结果只作检索辅助，不构成选导师建议
