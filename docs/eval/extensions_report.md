## 2. 消融实验 + 显著性检验

### 1. 方法

混合检索系统由三部分组成：
1. **BM25F 词法检索**：对姓名/拼音/关键词/研究方向/研究所/职称六个字段加权打分；
2. **主题模型相似度**：TF-IDF + NMF 得到教师主题分布（`data/exports/topics.json`），查询词投影到主题词空间后做余弦相似度；
3. **混合融合**：`(1-α)·BM25 + α·主题`（双方各自 min-max 归一化，主题分数只在 BM25 召回集内生效）。

对以下 7 个变体逐一评估，基线为 `full_hybrid`：

| 变体 | 说明 |
| --- | --- |
| `full_hybrid` | 混合 0.6 BM25 + 0.4 主题（基线） |
| `bm25_only` | 仅 BM25F |
| `topic_only` | 仅主题模型 |
| `hybrid_8_2` | 混合 0.8 BM25 + 0.2 主题 |
| `hybrid_2_8` | 混合 0.2 BM25 + 0.8 主题 |
| `rule_only` | 仅规则 relevance() |
| `random` | 随机排序（5 种子平均） |

评估查询共 38 条（人工标注；扩充集中带 relevant 标注的查询已并入，自动生成的无标注查询跳过）。指标：NDCG@10、MAP@10、HitRate@10、P@5，逐查询计算后取平均。显著性检验：Full hybrid vs 各变体的逐查询指标差值做配对 Wilcoxon 符号秩检验与配对 t 检验，α=0.05。

### 5. 分析

- **主题模型的增量价值**：Full hybrid（0.6/0.4）相对纯 BM25 的 NDCG@10 下降 0.0429（0.9263 → 0.8834）。主题分数在召回集内把部分词法匹配度更高的教师排后，说明当前主题分布与词法证据的区分方向不完全一致。
  - 该差异 Wilcoxon p=0.0061、t 检验 p=0.0063，在 α=0.05 下显著。
- **融合权重敏感性**：BM25 权重 0.8 时 NDCG=0.9048，0.2 时 0.7307。BM25 权重越大性能越好，词法检索是主要贡献者，当前 0.4 的主题权重偏大，可考虑降到 0.1~0.2。
- **纯主题模型**：NDCG=0.1112，远低于 BM25 单模型（0.9263）。主题粒度过粗，会把大量无关教师一并打分，缺乏词法精确匹配能力，单独使用无法支撑检索。
- **规则 relevance()**：NDCG=0.9878。规则对「研究方向子串命中」直接给高分且召回集内按姓名稳定排序；但其固定档位打分无法区分同档教师，泛化性有限。
- **随机下界**：NDCG=0.0135（5 种子平均），基线相对随机的提升 0.8699，说明混合检索远好于随机猜测。

**结论**：BM25F 词法检索是系统的核心组件（0.9263）；主题模型单独使用偏弱（粗粒度画像区分力有限），以 0.4 权重融合时对排序可能产生扰动，建议降低主题权重或改进主题粒度后再融合。随机排序作为下界验证了所有真实变体的显著优势。

## 4. 学生画像个性化推荐

### 方法说明

本实验采用**基于内容的过滤（Content-Based Filtering）**方法，根据学生画像中的研究兴趣、学院偏好和权重设置，对库内 773 位教师进行个性化排序。

**评分组成：**

| 维度 | 来源 | 说明 |
|---|---|---|
| 研究匹配 | `research_directions` + `keywords` 与学生兴趣 token 的 Jaccard | 值域 [0, 1]，越大表示方向越贴合 |
| 学术能力 | `processing.score`（min-max 归一化） | 论文数、引用数、h 指数、荣誉的综合评分 |
| 教学口碑 | `processing.teaching_score`（min-max 归一化） | 选课社区课程评分 |

**最终分数** = `w_research × 研究匹配` + `w_academic × 学术能力` + `w_teaching × 教学口碑`

**硬过滤**：`wants_phd_advisor=True` 时只保留博导；指定学院/研究所时进一步过滤。

### 权重敏感性分析

从五个演示画像可以观察以下规律：

1. **研究匹配权重（w_research）**：当学生兴趣方向明确（如 CV、芯片），提高 w_research 能让方向高度吻合的教师排名上升；但 Jaccard 分母是学生 token 数，如果兴趣描述过于宽泛（如只写'智能'），几乎所有教师都会拿到较高分，区分度下降。

2. **学术权重（w_academic）**：学术分来自综合评分（论文、引用、h 指数、荣誉），提高此权重会让高引用、高 h 指数的资深教师排名靠前，适合科研导向的学生。

3. **教学权重（w_teaching）**：教学分只覆盖选课社区有点评的约 498 位教师，其余教师教学分为 0（min-max 后偏低）。提高此权重适合本科/硕士阶段、重视课堂体验的学生；但需注意数据覆盖不全可能带来的偏差。

4. **硬过滤的影响**：`wants_phd_advisor=True` 会把候选池从 773 人缩小到 151 人（博导），候选池变小后 min-max 归一化的分数分布会变化，可能导致同一教师在'有博导/无博导'两种模式下的排名不同。


### 局限性

- Jaccard 匹配基于中文 bigram 分词，同义词（如'深度学习'与'神经网络'）无法自动关联；
- 教学评分覆盖率约 64%，缺失教师的 min-max 分偏低；
- Ground Truth 同样基于 token 交集，与真实相关性存在偏差；
- 未考虑师生比、招生名额、经费等实际选导师因素。

## 5. IsolationForest 异常检测

### 方法说明

使用 **IsolationForest（孤立森林）** 对每位教师的多维画像进行无监督异常检测，目的有二：(1) 发现**数据质量问题**（如字段缺失、爬取不全导致的组合异常）；(2) 识别**真正 exceptional** 的教师（学术产出、引用、荣誉等维度极端）。

#### 特征（13 维，缺失值按 0 处理）

- `paper_count`
- `citation_count`
- `h_index`
- `honor_count`
- `course_count`
- `avg_rating`
- `rating_count`
- `paper_citations_per_paper`
- `is_advisor`
- `is_phd_advisor`
- `processing_score`
- `teaching_score`
- `recent_papers_5y`

#### 预处理
1. 对 `citation_count`、`paper_count` 做 log1p 变换（值 >1 时），缓解右偏；

3. min-max 归一化到 [0,1]。

#### 模型参数
