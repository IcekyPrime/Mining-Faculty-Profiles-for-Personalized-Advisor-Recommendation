# 数据合并口径

> 实现：`scripts/merge_authoritative_data.py`
> 产物：`data/db/mentor.db`（合并后）+ `data/exports/merge_report.json`（本次合并统计）

## 为什么需要合并

项目库经历过一次"把查不到的数值写成 0"的处理：`citation_count` 有 734 人、`paper_count`
有 306 人是 0。0 和 NULL 在业务含义上完全不同（0 = 确实没有，NULL = 没有查到），
混用会让综合评分失真。

补录第 40 轮产出的 `mentor-整合版.db` 是逐人复核后的结果。合并前做了逐字段比对：

- 773 个教师 id 完全一致；
- `college / college_raw / is_advisor / is_phd_advisor / filter_reason / course_community_* /
  scholar_* / research_topics` 等字段：**没有任何"项目库有值而整合版无值"的情况**；
- 因此 teachers 表可以整表采用整合版，不需要逐格取舍。

## 合并规则

| 对象 | 规则 | 本次结果 |
|---|---|---|
| `teachers` | 整表采用整合版（严格超集） | 773 人 |
| `honors` | JSON 数组 / 纯文本统一成 JSON 数组；去 `[1]`、`1.`、`一、` 编号；保序去重 | 332 人格式被规范化 |
| `h_index` | `h=0` 且 `paper_count>=1` 视为跨来源冲突，置 NULL | 7 人 |
| `papers.year` | 不在 1950–2027 的值，按引用串重抽最后一个合理年份；抽不到置 NULL | 修复 7308 篇，置空 3667 篇 |
| `papers` | 按 (teacher_id, 规范化标题, 年份) 去重，保留被引最高一条 | 去重 564 条，最终 13088 篇 |
| `teachers.teaching_score` | 删除（与 `processing.teaching_score` 重复） | 删除 1 列 |
| `processing` | **不采用**整合版里的旧评分，合并后由 `processing/*.py` 全量重算 | 见下 |
| 备份 | 合并前自动复制到 `data/db/backup/mentor_before_merge_<时间戳>.db` | 自动 |

编号前缀的判定只认"数字 + 方括号/顿号"这种形式，`2023 IEEE MTT-S ...`、
`2006、2017年上海市...` 这类以年份开头的荣誉不会被误删。

## 操作步骤

```powershell
# 1. 合并权威数据（自动备份旧库）
python scripts/merge_authoritative_data.py --source "..\导师信息补录_258-515_第四十轮\mentor-整合版.db"

# 2. 重算处理层（顺序不能变：preprocess 会重建拼音索引与合作网络）
python processing/preprocess.py
python processing/keyword_extract.py
python processing/similarity_index.py
python processing/ranking.py
python processing/community.py
python processing/clustering.py
python processing/association.py
python processing/score.py

# 3. 生成数据质量报告
python scripts/data_quality_report.py
```

或直接 `make data SOURCE=...` + `make quality`。

## 回滚

```powershell
Copy-Item data\db\backup\mentor_before_merge_<时间戳>.db data\db\mentor.db -Force
```

（若只想恢复处理层结果，备份库里的 `processing` 表是合并前的版本，但口径不同，建议重跑。）

## 校验

合并后的数据由 `tests/test_data_integrity.py` 守住：

- honors 必须是 JSON 数组且不含编号前缀；
- 论文年份必须在 1950–2027；
- papers / courses 不得有孤儿 teacher_id；
- 不得存在 (教师, 标题, 年份) 完全重复的论文；
- `citation_count` 必须保留 NULL（防止又出现全 0 填充）；
- 综合评分必须在 0–100，`score_parts` 可解析且维度合法。

任何一条不满足，`pytest` 会失败，说明合并或重跑引入了回归。
