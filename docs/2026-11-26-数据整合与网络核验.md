## 五、核验边界

- **没有把 2,544 条新增论文全部逐条联网核验。** `doi_declared` 只表示 DOI 格式有效，不表示 DOI 已解析成功；`source_declared` 只表示来自最终补录快照。
- 教师官网只抽查了本次补录论文最多的 6 位教师，不是 773 人全量重抓。
- 杨杰的论文数/h 指数存在官网与 GitHub 口径冲突。官网是概数（“400多篇”“H-index 85”），库内是结构化字段；本次不强行用概数覆盖整数。
- `papers` 中仍有历史来源的碎片化标题和少量近似重复；这些主要来自 GitHub 原版，不是本次补录新增。本次未做全库标题清洗，避免误删真实论文。
- 补录新增的 2,544 篇论文多数没有结构化作者；本次把原有 1,998 条分号分隔的 `authors` 统一成 JSON 数组后，可从 `papers.authors` 对齐 489 位教师、2,012 篇论文、799 条边。与原版基线合并后为 2,938 条边、729 个节点；仍不能把它解释为完整合作关系。
